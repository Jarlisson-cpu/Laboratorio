# Laboratorio

Laboratório de testes automatizados em Python com **pytest**.

O projeto tem funções simples de e-commerce (cálculo de desconto com cupom, controle de estoque) e os testes unitários que verificam cada uma delas, incluindo os casos de erro.

## Estrutura

```
app/ecommerce.py          # funções de e-commerce
tests/test_ecommerce.py   # testes das funções do app
projeto pytest/           # exercício com mais funções e seus testes
main.py
```

## Como rodar os testes

Requisitos: Python 3 e pytest.

```bash
pip install pytest
pytest
```
